# Weather Dashboard

This is a simple SwiftUI project where I learned how to decode a nested JSON object.

## What I Learned

- Nested JSON Decoding
- Multiple Structs
- Using JSONDecoder
- Displaying decoded data in SwiftUI

## Technologies

- Swift
- SwiftUI
- JSONDecoder

## Project

The app displays:

- City
- Country
- Temperature
- Weather Condition
- Humidity

using fake JSON data.
