# Grocery List Viewer

A simple SwiftUI project that loads grocery data from JSON and displays it in a dynamic list.

## What I Learned

- Creating nested `Decodable` structs
- Decoding JSON using `JSONDecoder`
- Working with arrays of custom structs
- Using `ForEach` with `Identifiable`
- Using `UUID` for unique IDs
- Displaying dynamic data in SwiftUI

## Project

The app loads a store name and grocery items from JSON and displays each product with its name and quantity.
