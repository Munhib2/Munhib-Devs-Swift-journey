# Weather Snapshot

A simple SwiftUI project that loads weather data from JSON and displays it on screen.

## What I Learned

- Working with nested JSON
- Creating multiple Decodable structs
- Using JSONDecoder
- Modeling nested objects
- Passing decoded data to SwiftUI
- Updating UI using State variables

## Project

The app loads a city's weather information from JSON and displays the location, temperature, condition, and humidity.
