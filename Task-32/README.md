# Movie Detail Viewer

A simple SwiftUI project that loads movie information from JSON and displays it on screen.

## What I Learned

- Creating a Decodable model
- Decoding JSON using JSONDecoder
- Working with optional values
- Understanding null values in JSON
- Using String? for optional String data
- Displaying decoded data in SwiftUI

## Project

The app loads movie details from JSON and displays the title, rating, year, genre, director, and description.
