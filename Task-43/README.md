# 📱 GitHub User Finder - iOS App

A sleek, modern iOS application built using **SwiftUI** that allows users to search for GitHub profiles and view complete user statistics using the **GitHub REST API**.

---

## ✨ Features

- 🔍 **Real-time Search:** Search any GitHub profile by username.
- 👤 **Profile Overview:** View Avatar, Name, Handle, and Bio.
- 📊 **Key Metrics:** Live count for Repositories, Followers, and Following.
- 📌 **Extended Details:** Displays Location, Portfolio/Blog link, Account Creation, and Last Update dates.
- ⚡ **Asynchronous Networking:** Built with modern `async/await` and `URLSession` for clean, non-blocking UI rendering.
- 🎨 **Dark Mode UI:** Premium, modern dark-themed user interface.

---

## 🛠️ Tech Stack & Concepts

- **Language:** Swift 5.10+
- **Framework:** SwiftUI
- **Architecture:** MVVM / Component-driven UI
- **Networking:** `URLSession` (`async/await`)
- **Data Parsing:** `JSONDecoder` (Decodable Protocol)
- **Concurrency:** Swift Concurrency (`Task`, `MainActor`)
